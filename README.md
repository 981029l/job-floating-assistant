# JobFloatingAssistant (AI 求职悬浮助手)

> **基于 Android 原生无障碍与全局悬浮窗的“千岗千面”智能求职辅助 App**  
> 专为 **BOSS直聘、猎聘** 等移动端招聘场景打造：屏幕秒级无障碍提取 JD · 本地直连大模型 · 大模型全案简历解析回填 · 个性化定制破冰招呼语 · 一键复制防封号 · 纯单机 0 中间服务器依赖。

---

## 核心特性

### 可复制的生成错误详情（v1.4.3）

- 生成失败时，悬浮窗显示简短错误，并提供「查看错误详情」「复制错误详情」；展开后可选择文本，也可直接复制整份报告反馈。
- 「AI 设置」顶部集中展示「最近一次生成错误」，关闭悬浮窗或重启应用后仍可查看、复制或清除。仅在本机保存最后一份，不自动发送；成功生成或主动取消不会覆盖它。
- 报告包含时间、报告 ID、应用/Android 版本、场景、失败阶段与操作、总耗时/阶段耗时/请求耗时、模型、接口地址、实际超时配置、输入长度、HTTP 状态、请求 ID、响应长度、结束原因、接口错误摘要及异常链/调用栈。
- API Key、接口 URL 的认证信息/查询参数、常见令牌、手机号和邮箱会脱敏；不记录完整 JD、简历、聊天、提示词或模型响应正文。非 JSON 错误响应只保留状态、类型和长度；结构化接口错误保留脱敏后的 code/type/message 摘要。
- 当前网络超时配置仍为连接 20 秒、读取 45 秒、写入 20 秒。报告用于区分具体失败位置，不能仅凭旧截图中的 `timeout` 判断服务端故障原因。

### JD 对齐与两阶段生成（v1.4.2）

- 悬浮窗的 JD 预览、编辑内容和生成请求使用同一份岗位文本。手动修改或粘贴后，切换沟通场景也会使用修改后的 JD。
- 聊天页只有同时匹配招聘应用、公司和职位时才使用岗位记忆；不同公司的同名岗位分别保存。未确认 JD 时停止自动生成，可先进入岗位详情页读取，或展开「校对/修改」粘贴完整 JD。
- 岗位切换时清理旧页面累积内容，聊天文字不会写回 JD 记忆，推荐职位区域不参与岗位正文累积。
- 所有岗位、所有沟通场景统一使用两阶段流程：**当前完整 JD + 完整简历 → 逐项匹配 JSON → 本地校验 → 依据匹配结果生成话术**。每次点击生成都重新匹配，固定本次输入，不复用其他岗位或旧简历的匹配结果。悬浮窗显示「1/2 逐项对照」和「2/2 生成话术」。
- 第一阶段把 JD 按换行和句末标点分段编号，要求模型逐段拆解职责、必备条件、优先项和背景，为每项给出直接支持/相关经验/未体现的结论及简历原文引用。并列能力分别核对；不按简历项目顺序挑选卖点，也不把某个行业样例写成通用答案。
- 本地检查每段恰好出现一次、各项要求原文拼接覆盖整段、直接/相关结论有简历原文依据；允许排版空白差异。漏段、引用不存在、格式错误、无岗位要求或请求失败时终止，不降级为无依据的招呼语。程序验证覆盖与引用存在性，要求分类、证据相关性和最终文案语义仍依赖模型判断。
- 第二阶段接收校验后的完整匹配结果、同一份 JD/简历和聊天语境，优先选择主要职责的直接证据；相关经验保持边界，未体现的技能不能补造。自定义提示词仅作用于第二阶段的表达，不能跳过匹配；首次破冰、后续沟通和设置页试生成共享此流程。
- 每阶段请求都是一条 `system` 规则消息和一条 `user` JSON 资料消息，各资料独立存放。打招呼不重复传入通用「核心经历/AI 精炼优势」；新增经历需同步完善「完整简历原始文本」。自定义模板占位符指向资料字段，不替换资料内部文本。
- PDF 导入按页面位置排序，避免标题集中出现在正文前面导致项目经历串联。更新后需重新导入原 PDF，已保存的旧版文本不会自动重排。
- JD 编辑、切换沟通场景或关闭悬浮窗时取消进行中的网络请求；编辑 JD 后清除旧文案，需点击「按此JD重新生成」。取消后不继续第二阶段，不把旧结果显示到新输入下。
- 每条约 90-140 字，重点写实际工作及能力范围，不强行套用年限、指标或跨项目成果。关键技术未体现时，一条陈述真实经验范围，另一条可确认岗位分工；不把「简历未体现」写成「我不会」，也不拿通用经验包装成全面胜任。
- 删除默认提示词里固定的工作年限、业绩数字和示例项目；取消生成后对项目及技术名称的语义替换。缺少完整简历或 JD 时给出补充提示。正常生成调用模型两次，等待时间与 Token 用量增加；失败不自动重试，按需点击重试会从匹配阶段重新开始。
- v1.4.1 未修改的默认提示词自动迁移到新规则；自定义提示词保留，生成时共同遵守岗位与事实边界。模型输出仍需用户核对简历依据。

回归验证：在已安装 JDK 17、Android SDK 34 和 Gradle 8.7 的环境运行 `gradle testDebugUnitTest assembleRelease`。同一份模拟简历搭配不同公司的电商、直播、小程序、Java 后端岗位，检查每次先匹配再生成、证据与缺口独立传递；还覆盖遗漏/重复要求、虚构引用、简历变更、请求失败、取消、自定义提示词及全部沟通场景。原有岗位隔离、请求全文与模板字段测试保留。流程测试使用模拟模型响应，不证明真实模型已选对证据；个人简历不加入仓库。

真实模型验收需分别使用匹配程度高、只有相关经验、关键要求未体现的多个公司岗位：检查匹配项是否覆盖实际职责、引用能否支持结论、文案是否围绕当前岗位选材。医疗前端 JD 仅是其中一个回归素材；不能从 Canvas 外推三维引擎、从桌面交付外推指定桌面语言，或从 AI 编程外推 AI 产品经验。单元测试通过不代表语义质量与手机读屏效果已验收。

- **大模型简历全案结构化解析（v1.2.0）**：
  支持导入 PDF、Word (.docx)、纯文本简历或在输入框中直接粘贴原始正文。调用大模型智能提炼，自动一键解析并回填：
  - **求职意向**：目标岗位名称、期望薪资与目标城市；
  - **核心工作经历**：精炼浓缩 2-3 条主导项目与技术攻坚成效亮点；
  - **AI 精炼优势**：提炼 80-120 字黄金开场打招呼语料。
  彻底告别在手机上手动打字录入档案的繁琐流程。

- **真实连通性测速与动态模型拉取（v1.1.7）**：
  彻底拔除全盘虚假数据与写死 Mock 延迟。未配置 Key 时严格呈现离线状态；填入 API Key 后点击真实向端点发起 HTTP 探测，动态测算真实往返延迟（ms）并拉取可用模型列表。

- **持久化凭证与直接覆盖更新（v1.1.6）**：
  工程内置统一持久化的 `debug.keystore` 签名凭证。云端 CI/CD 构建出的 APK 签名始终一致，后续升级安装时直接下载覆盖即可，无需卸载旧版本，手机历史配置与档案完整保留。

- **底部导航栏方向感知平滑切换（v1.1.5）**：
  底部导航在「悬浮主控」、「求职档案」、「AI设置」之间切换时，采用 `AnimatedContent` 配合方向感知的平滑滑动转场动效。

- **精简舒展的视觉规范**：
  界面遵循 Google Stitch 规范。顶栏移除冗余挤压的版本胶囊与设置按钮，保持标题与在线状态平整美观；卡片统一采用圆角与双状态优雅排版。

- **全局轻量悬浮窗**：
  常驻屏幕侧边边缘，支持贴边半隐藏与自由拖拽，支持标准(56dp)/迷你(44dp)/放大(64dp)三档动态调节。

- **无障碍读屏 JD 抓取**：
  基于 Android 系统 `AccessibilityService`，点击悬浮球一瞬间遍历屏幕 View 节点，精准抓取岗位名、薪资与职责要求，无需 OCR，零识别延迟。

- **安全隐私与零封号风险**：
  所有大模型请求均由手机直接与 AI 接口端点通信，不经过任何中间服务器；不注入任何目标 App，不模拟点击投递，仅作读屏辅助与生成。

## 手机使用指南

### 第一步：初次授权
1. 打开 App，在「悬浮主控」页面点击 **【去开通】** 开启 **系统悬浮窗权限**；
2. 点击 **【去开通】** 进入系统设置，找到 **求职助手屏幕识别服务** 并开启（用于无障碍读取岗位 JD）；
3. 打开顶部开关启动招手猫悬浮窗。

### 第二步：配置 AI 模型
1. 切换到底部 **「AI 设置」** 页面；
2. 填入您的 **API Key**（支持 DeepSeek / 阿里通义千问 / OpenAI / OneAPI 等兼容 OpenAI 格式的接口）；
3. 点击 **【测试连通并获取模型】**，系统将进行真实网络 Ping 测速并拉取模型列表；
4. 选择或自定义模型底座（如 `deepseek-chat` 或 `deepseek-reasoner`）。

### 第三步：完善求职档案（支持 AI 一键自动填充）
1. 切换到底部 **「求职档案」** 页面；
2. 点击顶部 **【上传简历文件】** 选择手机中的 PDF/Word 简历，或在底部「完整简历原始文本」框中直接粘贴；
3. 系统将自动调用大模型解析，或点击 **【AI 一键智能解析并填入全案】**；
4. 意向岗位、薪资城市、核心经历与精炼开场白将自动填入各卡片，亦可点击卡片右上角【编辑】进行微调。

### 第四步：实战破冰打招呼
1. 前往 **BOSS直聘** 或 **猎聘**，进入任意感兴趣的岗位详情页；
2. 点击屏幕侧边的招手猫悬浮球；
3. 悬浮窗秒级读取当前屏幕岗位要求，并结合您的真实简历生成针对该岗位的专属定制话术；
4. 点击 **【复制此话术并关闭】**；
5. 进入招聘沟通聊天框，长按粘贴发送。
