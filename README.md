# JobFloatingAssistant (AI 求职悬浮助手)

> **基于 Android 原生无障碍与全局悬浮窗的“千岗千面”智能求职辅助 App**  
> 专为 **BOSS直聘、猎聘** 等移动端招聘场景打造：屏幕秒级无障碍提取 JD · 本地直连大模型 · 大模型全案简历解析回填 · 个性化定制破冰招呼语 · 一键复制防封号 · 纯单机 0 中间服务器依赖。

---

## 核心特性

- **大模型简历全案结构化解析（v1.2.0）**：
  支持导入 PDF、Word (.docx)、纯文本简历或在输入框中直接粘贴原始正文。调用大模型智能提炼，自动一键解析并回填：
  - **求职意向**：目标岗位名称、期望薪资与目标城市；
  - **核心工作经历**：精炼浓缩 2-3 条主导项目与技术攻坚成效亮点；
  - **AI 精炼优势**：提炼 80-120 字黄金开场打招呼语料。
  彻底告别在手机上手动打字录入档案的繁琐流程。

- **真实连通性测速与动态模型拉取（v1.1.7）**：
  彻底拔除全盘虚假数据与写死 Mock 延迟。未配置 Key 时严格呈现离线状态；填入 API Key 后点击真实向端点发起 HTTP 探测，动态测算真实往返延迟（ms）并拉取可用模型列表。

- **持久化凭证与直接覆盖更新（v1.1.6）**：
  工程内置统一持久化的 `debug.keystore` 签名凭证。云端 CI/CD 构建出的 APK 签名始终一致，后续升级安装时直接下载覆盖即可，无需卸载旧版本，手机历史配置与档案完整保留。

- **底部导航栏方向感知平滑切换（v1.1.5）**：
  底部导航在「悬浮主控」、「求职档案」、「AI设置」之间切换时，采用 `AnimatedContent` 配合方向感知的平滑滑动转场动效。

- **精简舒展的视觉规范**：
  界面遵循 Google Stitch 规范。顶栏移除冗余挤压的版本胶囊与设置按钮，保持标题与在线状态平整美观；卡片统一采用圆角与双状态优雅排版。

- **全局轻量悬浮窗**：
  常驻屏幕侧边边缘，支持贴边半隐藏与自由拖拽，支持标准(56dp)/迷你(44dp)/放大(64dp)三档动态调节。

- **无障碍读屏 JD 抓取**：
  基于 Android 系统 `AccessibilityService`，点击悬浮球一瞬间遍历屏幕 View 节点，精准抓取岗位名、薪资与职责要求，无需 OCR，零识别延迟。

- **安全隐私与零封号风险**：
  所有大模型请求均由手机直接与 AI 接口端点通信，不经过任何中间服务器；不注入任何目标 App，不模拟点击投递，仅作读屏辅助与生成。

## 手机使用指南

### 第一步：初次授权
1. 打开 App，在「悬浮主控」页面点击 **【去开通】** 开启 **系统悬浮窗权限**；
2. 点击 **【去开通】** 进入系统设置，找到 **求职助手屏幕识别服务** 并开启（用于无障碍读取岗位 JD）；
3. 打开顶部开关启动招手猫悬浮窗。

### 第二步：配置 AI 模型
1. 切换到底部 **「AI 设置」** 页面；
2. 填入您的 **API Key**（支持 DeepSeek / 阿里通义千问 / OpenAI / OneAPI 等兼容 OpenAI 格式的接口）；
3. 点击 **【测试连通并获取模型】**，系统将进行真实网络 Ping 测速并拉取模型列表；
4. 选择或自定义模型底座（如 `deepseek-chat` 或 `deepseek-reasoner`）。

### 第三步：完善求职档案（支持 AI 一键自动填充）
1. 切换到底部 **「求职档案」** 页面；
2. 点击顶部 **【上传简历文件】** 选择手机中的 PDF/Word 简历，或在底部「完整简历原始文本」框中直接粘贴；
3. 系统将自动调用大模型解析，或点击 **【AI 一键智能解析并填入全案】**；
4. 意向岗位、薪资城市、核心经历与精炼开场白将自动填入各卡片，亦可点击卡片右上角【编辑】进行微调。

### 第四步：实战破冰打招呼
1. 前往 **BOSS直聘** 或 **猎聘**，进入任意感兴趣的岗位详情页；
2. 点击屏幕侧边的招手猫悬浮球；
3. 悬浮窗秒级读取当前屏幕岗位要求，并结合您的真实简历生成针对该岗位的专属定制话术；
4. 点击 **【复制此话术并关闭】**；
5. 进入招聘沟通聊天框，长按粘贴发送。

## 项目工程结构

```text
job-floating-assistant/
├── .github/workflows/
│   └── build-apk.yml               # GitHub Actions 云端自动化编译打包发布流水线
├── debug.keystore                  # 固化的持久化统一调试签名证书（保障直接覆盖安装）
├── app/
│   ├── src/main/
│   │   ├── java/com/assistant/job/
│   │   │   ├── MainActivity.kt             # Jetpack Compose 主界面与多Tab联动控制
│   │   │   ├── FloatingService.kt          # WindowManager 全局悬浮窗与破冰卡片服务
│   │   │   ├── JobAccessibilityService.kt  # 无障碍读屏服务（节点遍历与文本智能去重）
│   │   │   ├── DeepSeekClient.kt           # 大模型直连引擎（真实Ping/模型拉取/全案提取/破冰生成）
│   │   │   ├── ResumeParser.kt             # PDF与Word文件原始文本流解析器
│   │   │   └── StorageManager.kt           # 本地持久化配置与档案中心（SharedPreferences）
│   │   ├── res/                            # 矢量图标与界面资源
│   │   └── AndroidManifest.xml             # 系统权限声明与服务组件注册
│   └── build.gradle.kts                    # 模块构建配置（签名绑定与依赖管理）
├── settings.gradle.kts
└── build.gradle.kts
```
